This page lists the locations where Gemini Enterprise and Gemini Notebook Enterprise are available, along with their data residency commitments for at-rest storage (at-rest DRZ) and artificial intelligence (AI) or machine learning processing (MLP).
Gemini Enterprise and Gemini Notebook Enterprise support at-rest DRZ in the multi-regions and in-country regions listed on this page, subject to limitations.
If you don't have security, or regulatory reasons to locate your customer data
in the us or eu multi-regions or the in-country regions with respect to at-rest
DRZ or MLP, Google recommends that you choose the global location. This is
because the global location provides better end-user response times, the
latest model versions, and the most up-to-date features. See
Limitations for multi-regions and in-country regions.
Multi-regions
The following tables list the multi-regions where Gemini Enterprise and Gemini Notebook Enterprise are available.
Gemini Enterprise multi-regions
The following table lists the multi-regions where Gemini Enterprise is available.

|---|---|
| API availability in the European Union | eu |
| API availability in the United States | us |
For Gemini Enterprise, MLP, such as training,
prediction, and model tuning, occurs within the us multi-region when requests
are made to regionally-available APIs in the US, or within the eu multi-region
when requests are made to regionally-available APIs in Europe, subject to the
limitations outlined below.

In-country regions
Using these locations is in GA with allowlist. To get access to these locations for use with Gemini Enterprise or Gemini Notebook Enterprise, contact your Google account team.
The following table lists the in-country regions and multi-regions where Gemini Enterprise and Gemini Notebook Enterprise are available.
| In-country description | In-country name |
|---|---|
| API availability in Canada | ca |
| API availability in India | in |
| API availability in Japan | asia-northeast1 |
| API availability in Singapore | sg |
| API availability in the United Kingdom | europe-west2 |
These locations provide at-rest DRZ within the specified location. These
in-country locations may be more constrained and have
limitations similar to the us and eu multi-regions.
Specify a multi-region for your data store
To confine your Customer Data to at-rest DRZ in the us or eu multi-region, follow
these steps:
- If you create the data store through the Google Cloud console, then choose us (multiple regions in the United States) or eu (multiple regions in the European Union) when you pick your app location. For more information, see Create an app.
- For API calls, replace global-discoveryengine ordiscoveryengine witheu-discoveryengine orus-discoveryengine , and replaceglobal witheu orus . The following table shows examples of the API paths:EU multi-region https://eu-discoveryengine.googleapis.com/v1/projects/PROJECT_ID/locations/eu/… US multi-region https://us-discoveryengine.googleapis.com/v1/projects/PROJECT_ID/locations/us/… Global multi-region (Two equivalent endpoints) With the global endpoint prefix:https://global-discoveryengine.googleapis.com/v1/projects/PROJECT_ID/locations/global/… Without the global endpoint prefix:https://discoveryengine.googleapis.com/v1/projects/PROJECT_ID/locations/global/…
- For Gemini Notebook Enterprise, ensure the user is licensed and is using a notebook in the selected region.
- Review the limitations associated with using a specific multi-region.
